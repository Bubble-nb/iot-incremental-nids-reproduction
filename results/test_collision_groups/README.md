以模型实际接收的 float32 四字段十包输入匹配，标签不参与分组。每个域选择包含正常类、正常支持数最多的异标签组，与预测结果无关。

- IoT-NID：866条，852条正常、14条dos-http；正常测试总数2,613，最大误报贡献32.6062个百分点。
- 正向种子1 Combined校准使TON_IoT组全部由MITM变为正常。MITM正确数137降为6，其中130条减少来自此组。
- 两块预测替换的双顺序平均分解：该组对Combined目标Macro-F1变化贡献−3.137769个百分点，总变化−3.374117个百分点，占92.9953%。这是固定模型预测的算术归因，不是训练因果干预。
- 反向Replay种子2该组输出正常，没有贡献误报，不能概括为所有运行都有这一误报来源。
